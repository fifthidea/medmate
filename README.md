# ماشین حساب دارویی MedMate

## نسخه pwa-2.6

چندی پیش، ماشین حساب محاسبات دارویی MedMate که به صورت رایگان بر بستر vercel به آدرس drug-c.vercel.app دیپلوی شده بود، از این آدرس حذف شد چون سازندگان تصمیم گرفتند که بجای آن، نسخه اندرویدی را در فروشگاه بازار به فروش بگذارند

نسخه pwa-2.6 که به صورت کش در مرورگ داشتم رو استخراج و توی Github Pages دیپلوی کردم تا بقیه بتونن کماکان به صورت رایگان از این ابزار استفاده کنند.

تنها تغییرات نسبت به آخرین نسخه اندرویدی (تا به الان)، نبود قسمت های محاسبه معکوس دوز و محاسبات داروهای ترکیبی هستش. تمامی قسمت ها تست شده و به درستی کار میکنند.

برای استفاده کافیه وارد آدرس [fifthidea.github.io/medmate](https://fifthidea.github.io/medmate) بشین.
